# 图片格式转换工具

这是一个简单易用的图片格式转换工具，支持批量转换图片格式。

## 功能特点

- 支持批量选择图片文件
- 支持多种图片格式转换（PNG、JPEG、BMP、GIF、TIFF、WebP）
- 可自定义输出目录
- 图形界面操作，简单直观
- 跨平台支持（Windows、macOS、Linux）

## 安装说明

1. 确保已安装Python 3.6或更高版本
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```

## 使用方法

1. 运行程序：
   ```bash
   python image_converter.py
   ```
2. 点击"选择图片文件"按钮选择要转换的图片
3. 选择输出目录
4. 从下拉菜单选择目标格式
5. 点击"开始转换"按钮进行转换

## 支持的格式

- PNG (.png)
- JPEG (.jpg)
- BMP (.bmp)
- GIF (.gif)
- TIFF (.tiff)
- WebP (.webp)

## 注意事项

- 转换过程中请勿关闭程序
- 确保有足够的磁盘空间
- 建议在转换前备份原始图片
